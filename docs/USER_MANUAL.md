## 1. 시스템 소개

KPROTEK 견적서 관리 시스템은 Notion 데이터베이스를 기반으로 견적서를 작성하고, 공개 링크를 통해 클라이언트에게 공유하여 승인/거부를 받을 수 있는 웹 애플리케이션입니다.

### 주요 기능

| 기능 | 설명 |
|------|------|
| 견적서 작성 | 항목, 수량, 금액을 입력하여 견적서 작성 |
| 공개 링크 공유 | 로그인 없이 접근 가능한 고유 링크 생성 |
| 클라이언트 승인/거부 | 클라이언트가 견적서를 확인 후 승인 또는 거부 |
| PDF 인쇄/저장 | 견적서를 PDF로 인쇄하거나 저장 |
| 모바일 지원 | 스마트폰, 태블릿 등 모바일 기기에서도 견적서 작성, 수정, 확인 가능 |
| 다국어 지원 | 한국어, 영어, 중국어, 일본어, 이탈리아어, 스페인어 |
| 자동 상태 관리 | 클라이언트 열람, 유효기간 만료 시 자동 상태 전환 |

### 모바일 기기 지원

본 시스템은 반응형 웹으로 설계되어 PC뿐만 아니라 스마트폰, 태블릿 등 모바일 기기에서도 동일한 기능을 사용할 수 있습니다.

- **관리자**: 모바일 브라우저에서 로그인하여 견적서 작성, 수정, 상태 확인이 가능합니다. 외근 중에도 실시간으로 견적서를 관리할 수 있습니다.
- **클라이언트**: 전달받은 공개 링크를 모바일에서 열어 견적서 확인, PDF 저장, 승인/거부를 바로 처리할 수 있습니다.

> **별도 앱 설치 없이** 모바일 브라우저(Chrome, Safari 등)에서 바로 사용 가능합니다.

## 2. 시작하기

### 2.1 접속 방법

- **관리자**: 브라우저에서 사이트 주소 접속 후 `관리자 로그인` 클릭
- **클라이언트**: 관리자로부터 전달받은 공개 링크로 직접 접속

### 2.2 관리자 로그인

1. 홈페이지에서 `관리자 로그인` 버튼 클릭
2. 이메일과 비밀번호 입력
3. `로그인` 버튼 클릭
4. 로그인 성공 시 대시보드로 자동 이동

> **참고**: 비밀번호 입력 시 눈 아이콘을 클릭하면 입력한 비밀번호를 확인할 수 있습니다.

## 3. 관리자 가이드

### 3.1 대시보드

로그인 후 표시되는 메인 화면입니다.

**구성 요소:**

- **통계 카드**: 각 상태별 견적서 개수를 한눈에 확인
  - 총 견적서 / 발송됨 / 확인됨 / 승인됨 / 거부됨 / 만료됨
- **검색**: 견적서 번호, 고객명, 프로젝트명으로 검색
- **상태 필터**: 특정 상태의 견적서만 필터링
- **견적서 목록**: 전체 견적서를 테이블 형태로 표시

> **자동 만료**: 대시보드 접속 시 유효기간이 지난 견적서는 자동으로 "만료됨" 상태로 변경됩니다.

---

### 3.2 새 견적서 작성

1. 대시보드 우측 상단의 `새 견적서` 버튼 클릭
2. 아래 정보를 입력합니다:

#### 기본 정보

| 필드 | 필수 | 설명 |
|------|------|------|
| 고객 선택 | O | 기존 고객 선택 또는 `새 고객 추가` 버튼으로 인라인 생성 |
| 프로젝트명 | - | 프로젝트 또는 공사 이름 |
| 언어 | O | 견적서 표시 언어 (기본값: 한국어) |
| 발행일 | O | 견적서 발행 날짜 (기본값: 오늘) |
| 유효기간 | O | 견적서 만료 날짜 (기본값: 발행일 + 30일) |
| 수신처 | - | 받는 곳 (예: OO회사 귀중) |
| 견적 담당자 | - | 담당자 이름 및 연락처 |
| 비고 | - | 견적 조건, 특이사항 등 |

#### 견적 항목

각 항목별로 아래 정보를 입력합니다:

| 필드 | 필수 | 설명 |
|------|------|------|
| 품목명 | O | 제품/서비스 이름 |
| 수량 | O | 수량 (최소 1) |
| 단가 | O | 개당 가격 |
| 단위 | - | 단위 (EA, 식, Set 등) |
| 설명 | - | 상세 설명 |
| 비고 | - | 추가 참고사항 |

- `항목 추가` 버튼으로 견적 항목을 추가할 수 있습니다
- 각 항목의 금액은 `수량 x 단가`로 자동 계산됩니다
- 하단에 전체 합계가 실시간으로 표시됩니다

3. 모든 정보 입력 후 `저장` 버튼 클릭

---

### 3.3 견적서 상세 확인

대시보드에서 견적서를 클릭하면 상세 페이지로 이동합니다.

**확인 가능한 정보:**
- 견적서 번호, 발행일, 유효기간
- 현재 상태
- 프로젝트명, 수신처, 견적 담당자
- 고객 정보 (이름, 회사명, 이메일, 전화번호)
- 견적 항목 테이블 (소계, 총액)
- 비고

---

### 3.4 견적서 수정

1. 견적서 상세 페이지에서 `수정` 버튼 클릭
2. 내용을 수정한 후 `저장` 버튼 클릭

> **주의**: 수정은 `작성중` 또는 `거부됨` 상태의 견적서만 가능합니다.

---

### 3.5 견적서 삭제

1. 견적서 상세 페이지에서 `삭제` 버튼 클릭
2. 확인 다이얼로그에서 `삭제` 버튼 클릭

> **주의**: 삭제된 견적서는 복구할 수 없습니다.

---

### 3.6 공개 링크 생성 및 공유

클라이언트에게 견적서를 공유하려면 공개 링크를 생성해야 합니다.

1. 견적서 상세 페이지 하단의 `공개 링크` 섹션 확인
2. `공개 링크 생성` 버튼 클릭
3. 생성된 링크를 복사 버튼으로 복사
4. 이메일, 메신저 등을 통해 클라이언트에게 전달

> **참고**: 공개 링크 생성 시 견적서 상태가 자동으로 `발송됨`으로 변경됩니다.

> **관리자 보호**: 관리자가 공개 링크에 접속해도 승인/거부 버튼은 표시되지 않습니다. 승인/거부는 클라이언트(비로그인 사용자)만 가능합니다.

## 4. 클라이언트 가이드

### 4.1 견적서 확인

1. 관리자로부터 전달받은 공개 링크를 브라우저에서 열기
2. 회사 공식 양식의 견적서가 표시됩니다:
   - 회사 정보 (상호, 사업자번호, 주소 등)
   - 견적 담당자 정보
   - 견적 항목 테이블 (품목, 수량, 단가, 금액)
   - 합계 금액
   - 견적 조건

### 4.2 PDF 인쇄/저장

1. 견적서 하단의 `PDF 다운로드` 버튼 클릭
2. 브라우저의 인쇄 대화상자가 열립니다
3. `PDF로 저장`을 선택하여 파일로 저장하거나 직접 인쇄

### 4.3 견적서 승인

1. 견적서 하단의 `승인` 버튼 클릭
2. **확인 다이얼로그**가 표시됩니다:
   - "견적서를 승인하시겠습니까?"
   - "승인 후에는 변경할 수 없습니다. 계속 진행하시겠습니까?"
3. `승인` 버튼을 클릭하여 확정하거나, `취소`로 돌아가기
4. 승인 완료 시 화면에 승인 완료 메시지가 표시됩니다

### 4.4 견적서 거부

1. 견적서 하단의 `거부` 버튼 클릭
2. **확인 다이얼로그**가 표시됩니다:
   - "견적서를 거부하시겠습니까?"
   - "거부 후에는 변경할 수 없습니다. 계속 진행하시겠습니까?"
3. `거부` 버튼을 클릭하여 확정하거나, `취소`로 돌아가기
4. 거부 완료 시 화면에 거부 완료 메시지가 표시됩니다

> **주의**: 승인 또는 거부 후에는 변경할 수 없습니다. 신중하게 결정해 주세요.

### 4.5 만료된 견적서

유효기간이 지난 견적서에 접속하면 만료 안내 화면이 표시됩니다.
새로운 견적서가 필요한 경우 `새 견적서 요청` 버튼을 클릭하여 담당자에게 이메일을 보낼 수 있습니다.

## 5. 견적서 상태 흐름

견적서는 다음과 같은 생명주기를 가집니다:

```
작성중 ──(공개 링크 생성)──> 발송됨 ──(클라이언트 열람)──> 확인됨
                                                            │
                                                    ┌───────┴───────┐
                                                    │               │
                                                 승인됨          거부됨
                                                                    │
                                                              (수정 가능)

※ 유효기간 경과 시 → 만료됨 (어떤 상태에서든 자동 전환)
```

### 상태별 설명

| 상태 | 색상 | 설명 | 관리자 가능 작업 |
|------|------|------|----------------|
| 작성중 | 회색 | 견적서 초기 작성 상태 | 수정, 삭제, 링크 생성 |
| 발송됨 | 파랑 | 공개 링크가 생성되어 클라이언트에게 전달된 상태 | 확인, 삭제 |
| 확인됨 | 노랑 | 클라이언트가 공개 링크를 열어 견적서를 확인한 상태 | 확인 |
| 승인됨 | 초록 | 클라이언트가 견적서를 승인한 상태 | 확인 |
| 거부됨 | 빨강 | 클라이언트가 견적서를 거부한 상태 | 수정, 삭제 |
| 만료됨 | 주황 | 유효기간이 경과하여 더 이상 유효하지 않은 상태 | 확인 |

## 6. 다국어 지원

견적서 작성 시 언어를 선택하면 클라이언트에게 보이는 모든 텍스트가 해당 언어로 표시됩니다.

### 지원 언어

| 언어 | 코드 | 전화번호 형식 |
|------|------|-------------|
| 한국어 | ko | 031-704-2989 (국내 형식) |
| English | en | +82-31-704-2989 (국제 형식) |
| 中文 | zh | +82-31-704-2989 (국제 형식) |
| 日本語 | ja | +82-31-704-2989 (국제 형식) |
| Italiano | it | +82-31-704-2989 (국제 형식) |
| Espanol | es | +82-31-704-2989 (국제 형식) |

### 번역되는 항목

- 견적서 제목 및 라벨
- 공급자 정보 (회사명, 주소 등)
- 테이블 헤더 (품목, 수량, 단가, 금액 등)
- 버튼 텍스트 (승인, 거부, PDF 다운로드)
- 시스템 메시지 (승인 완료, 만료 안내 등)
- 견적 담당자 전화번호 (자동 국제 형식 변환)
- 날짜 형식 (언어별 포맷)

> **참고**: 견적 항목의 품목명, 설명, 비고 등 사용자가 직접 입력한 내용도 자동 번역됩니다.

## 7. 자주 묻는 질문 (FAQ)

### Q1. 견적서를 수정하고 싶은데 수정 버튼이 없습니다.

**A**: 견적서가 `작성중` 또는 `거부됨` 상태일 때만 수정할 수 있습니다. 이미 발송되었거나 승인된 견적서는 수정할 수 없습니다.

### Q2. 클라이언트가 견적서를 잘못 승인/거부했습니다.

**A**: 승인/거부는 취소할 수 없습니다. 새로운 견적서를 작성하여 다시 공유해 주세요.

### Q3. 공개 링크가 작동하지 않습니다.

**A**: 견적서의 유효기간이 만료되었을 수 있습니다. 대시보드에서 해당 견적서의 상태를 확인해 주세요.

### Q4. 관리자가 공개 링크에서 승인/거부 버튼이 보이지 않습니다.

**A**: 정상입니다. 관리자 계정으로 로그인한 상태에서는 승인/거부 버튼이 표시되지 않습니다. 이는 관리자가 직접 승인/거부하는 것을 방지하기 위한 보안 기능입니다.

### Q5. 견적서의 금액 표시가 이상합니다.

**A**: 한국어 견적서의 경우 "일금 OOO원" 형태의 한글 금액 표기가 자동으로 생성됩니다. 다른 언어에서는 숫자 금액만 표시됩니다.

### Q6. 여러 언어로 같은 견적서를 보내고 싶습니다.

**A**: 동일한 내용으로 견적서를 언어별로 각각 작성해야 합니다. 언어 설정은 견적서 단위로 적용됩니다.
