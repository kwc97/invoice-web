# Notion 기반 견적서 관리 시스템 MVP PRD

## 🎯 핵심 정보

**목적**: Notion 데이터베이스 기반으로 견적서를 관리하고, 클라이언트가 웹에서 견적서를 확인하고 PDF로 다운로드할 수 있는 시스템

**사용자**: 비즈니스 오너/관리자(Notion에서 견적서 관리), 클라이언트(견적서 확인 및 PDF 다운로드)

## 🚶 사용자 여정

```
[관리자 워크플로우]
1. Notion에서 견적서 작성 (외부)
   ↓
2. 관리자 대시보드 페이지
   ↓ [견적서 목록 확인]

3. 견적서 상세 페이지 (관리자용)
   ↓ [공개 링크 생성 버튼]

4. 링크 복사 → 고객에게 수동 전송
   ↓
5. 대시보드에서 상태 모니터링

[클라이언트 워크플로우]
1. 이메일/메신저로 받은 링크 클릭
   ↓
2. 견적서 상세 페이지 (공개)
   ↓ [로그인 불필요]

3. 견적서 내용 확인
   ↓ [선택지]

   [PDF 다운로드] → PDF 파일 저장
   [승인] → Notion 상태 업데이트 → 완료 메시지
   [거부] → Notion 상태 업데이트 → 완료 메시지
```

## ⚡ 기능 명세

### 1. MVP 핵심 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **F001** | Notion 견적서 조회 | Notion API로 견적서 데이터를 실시간 동기화하여 조회 | 핵심 데이터 소스 연동 | 관리자 대시보드 페이지, 견적서 상세 페이지 (관리자용), 견적서 상세 페이지 (공개) |
| **F002** | 공개 링크 생성 | 각 견적서에 고유한 공개 접근 링크 자동 생성 | 클라이언트에게 견적서 공유하는 핵심 메커니즘 | 견적서 상세 페이지 (관리자용) |
| **F003** | 견적서 공개 조회 | 로그인 없이 고유 링크로 견적서 확인 가능 | 클라이언트 접근성 보장 | 견적서 상세 페이지 (공개) |
| **F004** | PDF 다운로드 | 견적서를 인쇄 친화적 PDF로 변환하여 다운로드 | 클라이언트가 견적서 보관 및 인쇄 | 견적서 상세 페이지 (공개) |
| **F005** | 견적서 상태 관리 | 클라이언트의 승인/거부를 Notion에 반영 | 견적서 진행 상태 추적 | 견적서 상세 페이지 (공개), 관리자 대시보드 페이지 |
| **F006** | 대시보드 통계 | 견적서 상태별 요약 (발송, 확인, 승인, 거부) | 전체 견적서 현황 파악 | 관리자 대시보드 페이지 |

## 📄 페이지별 상세 기능

### 로그인 페이지

> **구현 기능:** `F010` | **메뉴 위치:** 비로그인 사용자 → 로그인

| 항목 | 내용 |
|------|------|
| **역할** | 관리자 인증 전용 페이지 |
| **진입 경로** | • 비로그인 상태에서 관리자 페이지 접근 시 자동 리디렉션<br>• 직접 로그인 URL 접근 |
| **사용자 행동** | 이메일과 비밀번호를 입력하여 관리자로 로그인 |
| **주요 기능** | • 이메일 입력 필드 (유효성 검사)<br>• 비밀번호 입력 필드<br>• React Hook Form + Zod 검증<br>• **로그인** 버튼 (Server Action) |
| **다음 이동** | 성공 → 관리자 대시보드 페이지, 실패 → 에러 메시지 표시 |

| notes | 비고 및 조건 | Text |

## 📋 추가 구현 노트

### Notion API 통합 고려사항
1. **API 키 관리**: 환경 변수로 Notion Integration Token 보안 관리
2. **데이터 동기화**: Notion 데이터베이스를 실시간 조회 (캐싱 전략 고려)
3. **에러 처리**: Notion API 호출 실패 시 적절한 폴백 메시지

### PDF 생성 전략
1. **레이아웃**: 견적서 공개 페이지와 동일한 구조로 PDF 생성
2. **브랜딩**: 회사 로고, 색상, 폰트 일관성 유지
3. **인쇄 최적화**: A4 크기, 여백, 페이지 넘김 고려

### 공개 링크 보안
1. **고유 ID 생성**: UUID 또는 nanoid 사용
2. **링크 유효성**: 견적서 유효기간 이후 접근 제한 고려
3. **무단 접근 방지**: 링크를 아는 사람만 접근 가능 (추가 인증 없음)
